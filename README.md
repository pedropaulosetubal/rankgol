# RankGol

RankGol é uma plataforma de ranking de times de futebol desenvolvida como parte de um projeto acadêmico.

## Funcionalidades

- Página inicial da plataforma
- Página Sobre Nós
- Missão, visão e valores
- Ranking de times
- Aba Brasileirão Série A
- Aba Champions League
- Lista de times
- Lista de títulos
- Lista de artilheiros
- Lista de melhores jogadores
- Área autenticada
- Gestão de usuários com cadastro, alteração, ativação e inativação simulada

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo do projeto

O objetivo do projeto é criar uma plataforma visual e funcional para organizar informações sobre times de futebol, rankings, títulos, artilheiros e jogadores em destaque.
